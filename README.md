# Введение в программирование

Проект представляет собой учебные материалы для постепенного входа в программирование с нуля. Сейчас курс начинается с технической базы: как устроен компьютер, что делает операционная система, как работают файлы, числа, биты и простые битовые операции.

## Содержание

- [Введение](<./Введение/README.md>) - базовый раздел перед программированием: устройство ПК, ОС, командная строка, файловая система, форматы файлов, представление данных и битовые операции.
