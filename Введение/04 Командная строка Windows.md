# Командная строка Windows

## Цель темы

Научиться выполнять базовые действия с файлами и папками через PowerShell и понимать CMD-аналоги основных команд.

После этой темы ученик должен уметь:

- объяснить, что такое командная строка;
- отличать PowerShell от CMD;
- понимать текущую папку и относительные пути;
- отличать команду от аргумента;
- выполнять базовые команды для папок и файлов;
- находить CMD-аналог для базовой команды PowerShell;
- аккуратно проверять путь перед копированием, перемещением и удалением.

## Зачем это нужно программисту

Командная строка позволяет точно управлять действиями компьютера. Многие инструменты разработчика запускаются командами. Даже если ученик пока не пишет программы, ему полезно понимать текущую папку, путь, команду и результат выполнения.

## Подробное объяснение

CLI означает command-line interface, то есть интерфейс командной строки. Пользователь вводит текстовую команду, нажимает Enter, а система выполняет действие и выводит результат.

В Windows удобно использовать PowerShell. Он показывает текущую папку и ждет команду. Текущая папка важна: многие команды работают относительно нее.

### Приглашение командной строки

Приглашение командной строки - это текст перед местом ввода команды. Оно показывает, что оболочка готова принять команду.

В PowerShell приглашение часто выглядит примерно так:

```powershell
PS C:\Users\Student>
```

Здесь `C:\Users\Student` - текущая папка. Команду нужно вводить после символа `>`.

В CMD приглашение может выглядеть так:

```cmd
C:\Users\Student>
```

В учебных примерах приглашение обычно не записывают. Например, если в конспекте написано:

```powershell
pwd
```

значит нужно ввести только `pwd`, а не весь текст `PS C:\Users\Student> pwd`.

### Что такое PowerShell

PowerShell - современная командная оболочка и язык автоматизации в Windows.

Командная оболочка означает, что пользователь может вводить команды текстом и получать результат. Язык автоматизации означает, что команды можно объединять в сценарии, чтобы выполнять повторяющиеся действия автоматически.

PowerShell умеет работать с файлами, папками, процессами, службами, настройками системы и многими другими объектами Windows. Его команды часто имеют вид `Глагол-Существительное`, например `Get-Content`, `Copy-Item`, `Move-Item`, `Remove-Item`. Такой стиль делает команды более длинными, но обычно более понятными.

В PowerShell есть короткие псевдонимы для привычных команд: `ls`, `cd`, `pwd`, `echo`. Поэтому часть команд похожа на команды из других оболочек, но внутри PowerShell они могут быть связаны с более полными командами.

Для этого курса PowerShell выбран как основной вариант, потому что он установлен в Windows, подходит для практики с файлами и папками и встречается в современных инструкциях для разработчиков.

### Что такое CMD

CMD, или Command Prompt, - более старая командная оболочка Windows.

Она появилась раньше PowerShell и до сих пор доступна в Windows. CMD часто встречается в старых учебниках, инструкциях и системных подсказках.

CMD тоже позволяет переходить по папкам, смотреть файлы, копировать, перемещать, удалять и запускать программы. Но ее команды обычно короче и менее единообразны: `dir`, `copy`, `move`, `del`, `ren`.

В этом курсе основной вариант - PowerShell, но полезно знать CMD-аналоги базовых команд: они встречаются в старых инструкциях, школьных материалах и документации.

### Главное различие

PowerShell и CMD решают похожую задачу: позволяют управлять компьютером с помощью текстовых команд. Но это разные оболочки с разным синтаксисом и разными возможностями.

Кратко:

- PowerShell современнее и мощнее;
- CMD проще по некоторым базовым командам, но менее единообразна;
- PowerShell часто работает с объектами Windows, а CMD в основном работает с текстовым выводом команд.

Команда может состоять из имени и аргументов. Например, `cd Documents` означает перейти в папку `Documents`. Здесь `cd` - команда, а `Documents` - аргумент.

Аргументы уточняют, что именно должна сделать команда. В команде `Copy-Item notes.txt notes-copy.txt` первый аргумент - что копировать, второй - куда или под каким именем создать копию.

Если путь содержит пробелы, его нужно брать в кавычки:

```powershell
cd "C:\Users\Student\My Documents"
```

Без кавычек PowerShell может решить, что это несколько разных аргументов, а не один путь.

### Почему команды так называются

Многие короткие команды появились как сокращения английских слов. Это помогает их запоминать: название команды часто подсказывает действие.

Примеры:

| Команда | От чего сокращение | Смысл |
|---|---|---|
| `cd` | change directory | сменить папку |
| `mkdir` | make directory | создать папку |
| `pwd` | print working directory | показать текущую папку |
| `ls` | list | показать список файлов и папок |
| `dir` | directory | показать содержимое папки в CMD |
| `del` | delete | удалить файл в CMD |
| `ren` | rename | переименовать файл или папку в CMD |
| `echo` | echo | вывести текст обратно в терминал |

У PowerShell есть и более длинные имена команд. Например, `Copy-Item` читается почти как английская фраза "скопировать объект", а `Remove-Item` - "удалить объект". Короткие команды вроде `ls`, `cd` и `pwd` в PowerShell часто являются удобными псевдонимами для более полных команд.

## Разбор базовых команд

### `pwd`

Команда `pwd` показывает текущую папку.

Синтаксис:

```powershell
pwd
```

Аргументы обычно не нужны.

Пример:

```powershell
pwd
```

Возможный результат:

```text
Path
----
C:\Users\Student
```

Зачем нужна: перед выполнением команд полезно понимать, где вы сейчас находитесь. Многие команды работают относительно текущей папки.

Типичная ошибка: ученик думает, что находится в папке проекта, но PowerShell открыт в домашней папке пользователя.

Аналог в CMD:

```cmd
cd
```

В CMD команда `cd` без аргументов показывает текущую папку. В PowerShell для этого удобнее использовать `pwd`.

### `ls`

Команда `ls` показывает содержимое папки: файлы и вложенные папки.

Синтаксис:

```powershell
ls
ls путь
```

Аргументы:

- без аргументов показывает содержимое текущей папки;
- `путь` указывает, какую папку нужно показать.

Примеры:

```powershell
ls
ls Documents
ls "C:\Users\Student\Desktop"
```

Зачем нужна: помогает проверить, какие файлы и папки есть в нужном месте.

Типичная ошибка: указать путь к файлу вместо папки или ошибиться в имени папки.

Примечание: в PowerShell `ls` - короткий псевдоним команды `Get-ChildItem`.

Аналог в CMD:

```cmd
dir
dir путь
```

В CMD команда `dir` показывает файлы и папки. Это ближайший аналог `ls`.

### `cd`

Команда `cd` меняет текущую папку.

Синтаксис:

```powershell
cd путь
```

Аргументы:

- `путь` - папка, в которую нужно перейти;
- `..` означает перейти на один уровень вверх;
- `.` означает текущую папку.

Примеры:

```powershell
cd Documents
cd ..
cd "C:\Users\Student\Desktop"
```

Зачем нужна: перед работой с файлами нужно перейти в нужную папку.

Типичные ошибки:

- попытаться перейти в файл, а не в папку;
- забыть кавычки в пути с пробелами;
- использовать относительный путь, не проверив текущую папку.

Примечание: в PowerShell `cd` - короткий псевдоним команды `Set-Location`.

Аналог в CMD:

```cmd
cd путь
cd ..
cd /d D:\Folder
```

В CMD команда `cd` тоже меняет текущую папку. Для перехода на другой диск часто нужно отдельно указать диск, например `D:`, или использовать `cd /d D:\Folder`.

### `mkdir`

Команда `mkdir` создает новую папку.

Синтаксис:

```powershell
mkdir имя_папки
mkdir путь_к_папке
```

Аргументы:

- `имя_папки` - имя новой папки в текущей папке;
- `путь_к_папке` - путь, где нужно создать папку.

Примеры:

```powershell
mkdir Course
mkdir lesson-01
mkdir "C:\Users\Student\Desktop\Intro Course"
```

Зачем нужна: позволяет создавать структуру проекта или учебных материалов.

Типичные ошибки:

- создать папку не там, где планировалось, из-за неверной текущей папки;
- попытаться создать папку с именем, которое уже занято;
- забыть кавычки в имени с пробелами.

Примечание: в PowerShell `mkdir` - удобный псевдоним для создания папок через `New-Item`.

Аналог в CMD:

```cmd
mkdir имя_папки
md имя_папки
```

В CMD `mkdir` и `md` создают папку. Для создания файла они не подходят.

### `New-Item`

Команда `New-Item` создает новый объект: файл или папку.

Синтаксис:

```powershell
New-Item имя_файла
New-Item имя_файла -ItemType File
New-Item имя_папки -ItemType Directory
```

Аргументы:

- первый аргумент - имя или путь создаваемого объекта;
- `-ItemType File` явно говорит, что нужно создать файл;
- `-ItemType Directory` явно говорит, что нужно создать папку.

Примеры:

```powershell
New-Item notes.txt
New-Item notes.md -ItemType File
New-Item practice -ItemType Directory
```

Зачем нужна: это более универсальная команда, чем `mkdir`. Через нее можно создавать и файлы, и папки.

Типичные ошибки:

- создать файл без расширения, хотя ожидался `.txt` или `.md`;
- создать объект не в той папке;
- не заметить, что файл уже существует.

Аналоги в CMD:

```cmd
type nul > notes.txt
mkdir practice
md practice
```

В CMD нет одного полного аналога `New-Item` для любых объектов. Для папок используют `mkdir` или `md`. Для создания пустого файла часто используют перенаправление вывода: `type nul > notes.txt`.

### `Get-Content`

Команда `Get-Content` читает содержимое текстового файла и выводит его в терминал.

Синтаксис:

```powershell
Get-Content путь_к_файлу
```

Аргументы:

- `путь_к_файлу` - файл, содержимое которого нужно вывести.

Примеры:

```powershell
Get-Content notes.txt
Get-Content "C:\Users\Student\Desktop\notes.txt"
```

Зачем нужна: позволяет быстро посмотреть текстовый файл без открытия отдельного редактора.

Типичные ошибки:

- попытаться прочитать бинарный файл как текст;
- указать путь к папке вместо файла;
- получить непонятные символы из-за неподходящей кодировки или бинарного формата.

Аналог в CMD:

```cmd
type notes.txt
```

В CMD команда `type` выводит содержимое текстового файла в терминал.

### `Copy-Item`

Команда `Copy-Item` копирует файл или папку.

Синтаксис:

```powershell
Copy-Item откуда куда
```

Аргументы:

- `откуда` - файл или папка, которую нужно скопировать;
- `куда` - новое место или новое имя копии.

Примеры:

```powershell
Copy-Item notes.txt notes-copy.txt
Copy-Item notes.txt backup\notes.txt
Copy-Item "C:\Users\Student\Desktop\notes.txt" "C:\Users\Student\Documents\notes.txt"
```

Зачем нужна: позволяет сделать копию перед изменениями или перенести данные в другую учебную папку, оставив оригинал.

Типичные ошибки:

- перепутать порядок аргументов;
- указать папку назначения, которой не существует;
- случайно заменить существующий файл.

Аналоги в CMD:

```cmd
copy notes.txt notes-copy.txt
xcopy source-folder backup-folder
robocopy source-folder backup-folder
```

Для простого копирования файлов в CMD используют `copy`. Для папок чаще используют `xcopy` или `robocopy`, но для новичков достаточно знать `copy` для файлов.

### `Move-Item`

Команда `Move-Item` перемещает или переименовывает файл или папку.

Синтаксис:

```powershell
Move-Item откуда куда
```

Аргументы:

- `откуда` - существующий файл или папка;
- `куда` - новое место или новое имя.

Примеры:

```powershell
Move-Item notes-copy.txt archive.txt
Move-Item archive.txt backup\archive.txt
Move-Item lesson-01 old-lesson-01
```

Зачем нужна: если `куда` находится в той же папке, команда фактически переименовывает объект. Если `куда` находится в другой папке, команда перемещает объект.

Типичные ошибки:

- думать, что перемещение оставляет копию на старом месте;
- перепутать исходный и конечный путь;
- переместить файл в неправильную папку из-за относительного пути.

Аналоги в CMD:

```cmd
move notes-copy.txt archive.txt
ren old-name.txt new-name.txt
rename old-name.txt new-name.txt
```

В CMD `move` перемещает файл или папку и может использоваться для переименования. Команды `ren` и `rename` специально переименовывают.

### `Remove-Item`

Команда `Remove-Item` удаляет файл или папку.

Синтаксис:

```powershell
Remove-Item путь
```

Аргументы:

- `путь` - файл или папка, которую нужно удалить.

Примеры:

```powershell
Remove-Item archive.txt
Remove-Item old-notes.txt
```

Зачем нужна: удаляет ненужные временные файлы и папки.

Типичные ошибки:

- удалить не тот файл из-за неверной текущей папки;
- использовать относительный путь, не проверив `pwd`;
- пытаться удалить папку, в которой есть файлы, без понимания последствий.

Важно: удаление через командную строку требует осторожности. Перед удалением полезно выполнить `pwd` и `ls`, чтобы проверить текущую папку и список файлов.

Аналоги в CMD:

```cmd
del archive.txt
erase archive.txt
rmdir folder-name
rd folder-name
```

В CMD `del` и `erase` удаляют файлы. `rmdir` и `rd` удаляют папки. Для папок с содержимым нужны дополнительные параметры, поэтому на вводном занятии лучше не использовать их без отдельного разбора.

### `echo`

Команда `echo` выводит текст в терминал.

Синтаксис:

```powershell
echo текст
```

Аргументы:

- `текст` - то, что нужно вывести.

Примеры:

```powershell
echo Hello
echo "Intro to CS"
```

Зачем нужна: помогает быстро проверить ввод команды, вывести сообщение или создать простой текстовый вывод.

Примечание: в PowerShell `echo` - псевдоним команды `Write-Output`.

Аналог в CMD:

```cmd
echo Hello
```

В CMD `echo` тоже выводит текст в терминал.

## Краткая памятка

Соответствие базовых команд:

| Действие | PowerShell | CMD |
|---|---|---|
| Показать текущую папку | `pwd` | `cd` |
| Показать файлы и папки | `ls` | `dir` |
| Перейти в папку | `cd путь` | `cd путь` |
| Создать папку | `mkdir имя` | `mkdir имя` или `md имя` |
| Создать пустой файл | `New-Item file.txt` | `type nul > file.txt` |
| Прочитать текстовый файл | `Get-Content file.txt` | `type file.txt` |
| Скопировать файл | `Copy-Item a.txt b.txt` | `copy a.txt b.txt` |
| Переместить файл | `Move-Item a.txt folder\a.txt` | `move a.txt folder\a.txt` |
| Переименовать файл | `Move-Item old.txt new.txt` | `ren old.txt new.txt` |
| Удалить файл | `Remove-Item file.txt` | `del file.txt` |
| Вывести текст | `echo "Text"` | `echo Text` |

Базовый набор команд:

```powershell
pwd
ls
cd Documents
mkdir Course
New-Item notes.txt
Get-Content notes.txt
Copy-Item notes.txt notes-copy.txt
Move-Item notes-copy.txt archive.txt
Remove-Item archive.txt
echo "Done"
```

Примерно тот же набор действий в CMD:

```cmd
cd
dir
cd Documents
mkdir Course
type nul > notes.txt
type notes.txt
copy notes.txt notes-copy.txt
move notes-copy.txt archive.txt
del archive.txt
echo Done
```

Некоторые команды ничего не выводят, если действие прошло успешно. Это нормально. Ошибка обычно появляется, если путь неверный, файла нет или недостаточно прав.

Командная строка требует точности. Если ошибиться в имени папки или забыть кавычки вокруг пути с пробелами, команда может не выполниться.

## Примеры

Создание папки и файла:

```powershell

```

```powershell

```

Путь с пробелами нужно брать в кавычки:

```powershell

```
