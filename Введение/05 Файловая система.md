# Файловая система

## Цель темы

Понять, как файлы и папки организованы на диске и как к ним обращаться по путям.

После этой темы ученик должен уметь:

- объяснить, что такое файл, папка и файловая система;
- читать путь Windows по частям;
- отличать абсолютный путь от относительного;
- понимать текущую папку;
- использовать `.` и `..` в путях;
- объяснить, зачем нужны расширения файлов;
- понимать, почему скрытые файлы обычно не показываются пользователю.

## Зачем это нужно программисту

Программы постоянно читают и записывают файлы: открывают настройки, сохраняют данные, загружают изображения, создают отчеты, читают входные данные для задач.

Ошибки с путями - одна из частых проблем новичков. Программа может быть правильной, но не находить файл, потому что файл лежит в другой папке или путь записан относительно не той текущей папки.

Если ученик понимает абсолютные и относительные пути, текущую папку и расширения, ему проще:

- запускать инструменты из командной строки;
- находить файлы проекта;
- понимать сообщения "файл не найден";
- аккуратно работать с папками и файлами;
- отличать имя файла от его содержимого.

## Подробное объяснение

Файловая система - это способ организовать данные на диске. Пользователь видит файлы и папки, но ОС хранит о них больше информации: имя, размер, дату изменения, права доступа и место, где данные находятся на носителе.

Для начала достаточно простой модели:

```text
диск -> папки -> вложенные папки -> файлы
```

Файл - это именованный набор данных. Например, `homework.txt`, `photo.png`, `game.exe`.

Папка - это контейнер для файлов и других папок. Папка помогает группировать данные: учебные материалы отдельно, фотографии отдельно, программы отдельно.

### Дерево папок

Папки образуют дерево. У дерева есть верхний уровень, ветви и вложенные элементы.

Пример:

```text
intro-course
├── lesson-01
│   └── notes.txt
├── lesson-02
│   └── task.txt
└── practice
    └── draft.md
```

Здесь:

- `intro-course` - главная папка примера;
- `lesson-01`, `lesson-02`, `practice` - вложенные папки;
- `notes.txt`, `task.txt`, `draft.md` - файлы.

Одинаковые имена файлов могут встречаться в разных папках. Например, можно иметь два файла `notes.txt`:

```text
lesson-01\notes.txt
lesson-02\notes.txt
```

Это разные файлы, потому что они лежат в разных местах.

### Диски и корень диска

В Windows путь часто начинается с буквы диска:

```text
C:\
```

`C:\` - корень диска `C`. Корень - это самый верхний уровень диска.

Примеры:

- `C:\` - корень диска `C`;
- `D:\` - корень диска `D`, если такой диск есть;
- `C:\Users` - папка `Users` в корне диска `C`;
- `C:\Users\Student` - папка `Student` внутри `Users`.

Важно: `C:` и `D:` могут быть разными физическими дисками, разделами одного диска или подключенными накопителями. Для этой темы достаточно понимать, что буква диска - начало пути в Windows.

### Из чего состоит путь

Путь показывает, где находится файл или папка.

Пример:

```text
C:\Users\Student\Desktop\homework.txt
```

Этот путь читается слева направо:

1. `C:\` - диск и его корень.
2. `Users` - папка в корне диска.
3. `Student` - папка внутри `Users`.
4. `Desktop` - папка внутри `Student`.
5. `homework.txt` - файл внутри `Desktop`.

В Windows части пути обычно разделяются обратной косой чертой:

```text
\
```

Не нужно путать ее с обычной косой чертой `/`. Во многих командах Windows часто понимает оба варианта, но в учебных путях Windows лучше использовать `\`.

### Абсолютный путь

Абсолютный путь указывает место полностью, начиная от корня диска.

Пример:

```text
C:\Users\Student\Documents\lesson.txt
```

Такой путь не зависит от того, где сейчас открыт PowerShell или проводник. Если файл существует именно там, абсолютный путь указывает на него полностью.

Абсолютный путь полезен, когда нужно точно указать место файла.

Минус: абсолютные пути часто зависят от конкретного компьютера и имени пользователя. Например, у одного ученика путь может быть:

```text
C:\Users\Student\Documents\lesson.txt
```

а у другого:

```text
C:\Users\Anna\Documents\lesson.txt
```

### Относительный путь

Относительный путь указывает место не от корня диска, а относительно текущей папки.

Пример:

```text
Documents\lesson.txt
```

Если текущая папка:

```text
C:\Users\Student
```

то путь `Documents\lesson.txt` означает:

```text
C:\Users\Student\Documents\lesson.txt
```

Но если текущая папка другая:

```text
C:\Users\Student\Desktop
```

то тот же относительный путь будет означать:

```text
C:\Users\Student\Desktop\Documents\lesson.txt
```

Поэтому относительный путь зависит от текущей папки.

### Текущая папка

Текущая папка - это папка, относительно которой выполняются команды с относительными путями.

В PowerShell текущую папку можно посмотреть командой:

```powershell
pwd
```

Содержимое текущей папки можно посмотреть командой:

```powershell
ls
```

Если команда не находит файл, первый вопрос должен быть таким: "В какой текущей папке я нахожусь?"

### `.` и `..`

В путях часто встречаются специальные обозначения:

| Обозначение | Значение |
|---|---|
| `.` | текущая папка |
| `..` | родительская папка, то есть папка на один уровень выше |

Пример дерева:

```text
course
├── lesson-01
│   └── notes.txt
└── practice
    └── task.txt
```

Если текущая папка:

```text
course\lesson-01
```

то путь:

```text
..\practice\task.txt
```

означает:

1. `..` - подняться из `lesson-01` в `course`;
2. `practice` - перейти в папку `practice`;
3. `task.txt` - взять файл `task.txt`.

### Имя файла и расширение

Расширение - часть имени файла после последней точки.

Примеры:

| Имя файла | Расширение |
|---|---|
| `notes.txt` | `.txt` |
| `photo.png` | `.png` |
| `archive.zip` | `.zip` |
| `program.exe` | `.exe` |
| `report.final.md` | `.md` |

Расширение помогает ОС и пользователю понять, какой программой обычно открывать файл.

Но расширение - это только часть имени. Если переименовать `photo.png` в `photo.txt`, содержимое файла не станет обычным текстом. Поэтому расширение может подсказать тип файла, но не доказывает его реальный формат.

### Скрытые файлы и папки

Скрытые файлы и папки - это элементы, которые проводник обычно не показывает в обычном режиме.

Они нужны, чтобы не перегружать пользователя служебными деталями. Многие системные и программные файлы не предназначены для случайного изменения.

Для программиста важно знать, что скрытые файлы существуют. В проектах могут встречаться служебные папки и файлы, которые редактор или проводник показывает не всегда.

На вводном занятии не нужно менять скрытые системные файлы. Достаточно понимать, что отсутствие файла на экране не всегда означает, что его нет.

### Типичные ошибки с путями

Ошибка 1. Текущая папка не та.

```powershell
Get-Content notes.txt
```

Команда ищет `notes.txt` в текущей папке. Если файл лежит в другой папке, появится ошибка.

Ошибка 2. Перепутан абсолютный и относительный путь.

```powershell
Get-Content Documents\notes.txt
```

Такой путь зависит от текущей папки. Если текущая папка не содержит папку `Documents`, команда не сработает.

Ошибка 3. Путь с пробелами записан без кавычек.

```powershell
cd C:\Users\Student\My Documents
```

Правильнее:

```powershell
cd "C:\Users\Student\My Documents"
```

Ошибка 4. У файла скрыто расширение.

Пользователь видит `photo.jpg`, но полное имя может быть `photo.jpg.exe`, если отображение расширений отключено. Поэтому расширения важно уметь показывать.

## Примеры

### Пример 1. Разбор абсолютного пути

Путь:

```text
C:\Users\Student\Desktop\homework.txt
```

означает:

- диск `C:`;
- папка `Users`;
- папка `Student`;
- папка `Desktop`;
- файл `homework.txt`.

### Пример 2. Относительный путь из текущей папки

Текущая папка:

```text
C:\Users\Student\intro-course
```

Файл:

```text
C:\Users\Student\intro-course\lesson-01\notes.txt
```

Относительный путь:

```text
lesson-01\notes.txt
```

### Пример 3. Переход через `..`

Текущая папка:

```text
C:\Users\Student\intro-course\lesson-01
```

Нужно обратиться к файлу:

```text
C:\Users\Student\intro-course\practice\task.txt
```

Относительный путь:

```text
..\practice\task.txt
```

Сначала `..` поднимает на уровень выше в `intro-course`, затем путь спускается в `practice`.

### Пример 4. Одинаковые имена в разных папках

Два файла могут называться одинаково:

```text
lesson-01\notes.txt
lesson-02\notes.txt
```

Для ОС это разные файлы, потому что полный путь у них разный.

## Практика на занятии

1. Найдите папку пользователя в Windows.
2. Найдите папки "Рабочий стол", "Документы", "Загрузки".
3. Создайте файл `notes.txt` в учебной папке и запишите его абсолютный путь.
4. Откройте PowerShell в учебной папке и выполните `pwd`.
5. Обратитесь к `notes.txt` относительным путем.
6. Создайте две папки `lesson-01` и `lesson-02`, а внутри каждой файл `notes.txt`.
7. Запишите абсолютные пути к обоим файлам `notes.txt`.
8. Включите отображение расширений файлов в проводнике, если это разрешено.
